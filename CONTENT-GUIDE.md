## 💾 How to Save Content

### Text Content
1. Copy text directly from the website
2. Paste into a Word/Google Doc
3. Clean up formatting
4. Organize by page/section

### Images
1. Right-click and "Save Image As"
2. Save with descriptive names (e.g., `microsoft-logo.png`, `hero-bg.jpg`)
3. Organize into appropriate folders
4. Note original URLs for reference

### Screenshots
1. Use browser developer tools or screenshot tools
2. Capture full-width for responsive testing
3. Save in high resolution

## ⚠️ Important Notes

1. **Copyright:** Ensure you have rights to use all content and images
2. **Image Optimization:** Compress images before uploading (use TinyPNG, Squoosh)
3. **Consistency:** Use consistent naming conventions
4. **Backup:** Keep original high-resolution versions
5. **Updates:** Note content that needs regular updates (blog, news)
