# Blog Images

Add blog post featured images to this folder.

## Required Blog Images

Add at least 3 blog post images to populate the homepage and blog page:

1. **blog-1.jpg** - Featured image for first blog post
2. **blog-2.jpg** - Featured image for second blog post
3. **blog-3.jpg** - Featured image for third blog post
4. Add more as needed...

## Image Requirements

- **Format**: JPG or WebP
- **Dimensions**: 800x600px (landscape) recommended
- **Size**: Under 200KB (optimized)
- **Quality**: High quality, professional
- **Subject**: Related to technology, IT, business

## Content Ideas

Blog images should relate to topics like:
- Cloud computing
- Cybersecurity
- Digital transformation
- IT infrastructure
- Business technology
- Data analytics
- Software development
- Networking

## Naming Convention

```
blog-1.jpg
blog-2.jpg
blog-3.jpg
cloud-computing-2025.jpg
cybersecurity-tips.jpg
digital-transformation.jpg
```

Use descriptive names when possible for better organization.

## Optimization

Before adding images:
1. Resize to 800x600px
2. Compress to reduce file size
3. Use JPG format (85-90% quality)
4. Or use WebP for better compression

Tools:
- [TinyJPG](https://tinyjpg.com/)
- [Squoosh](https://squoosh.app/)
- [ImageOptim](https://imageoptim.com/) (Mac)
