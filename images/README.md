# Images Folder Guide

This folder contains all images for the Techworld website.

## 📁 Folder Structure

```
images/
├── logo.png              ← Main company logo (transparent PNG)
├── favicon-16x16.png     ← Favicon 16x16px
├── favicon-32x32.png     ← Favicon 32x32px
├── apple-touch-icon.png  ← Apple touch icon 180x180px
├── og-image.jpg          ← Social media share image (1200x630px)
├── services/             ← Service images
├── solutions/            ← Solution images
├── blog/                 ← Blog post images
├── partners/             ← Partner/customer logos
├── team/                 ← Team member photos
└── banners/              ← Hero and banner images
```

## 🖼️ Image Requirements

### Logo & Branding
- **logo.png**: 200x50px (or similar ratio), transparent PNG
- **favicon-16x16.png**: 16x16px, PNG
- **favicon-32x32.png**: 32x32px, PNG
- **apple-touch-icon.png**: 180x180px, PNG
- **og-image.jpg**: 1200x630px, JPG (for social media)

### Where to Get Images
Visit **https://www.techworld-it.com** and download:
1. Company logo from header
2. Partner logos from partners section
3. Service and solution images
4. Blog post images
5. Any other relevant images

## 📥 How to Add Images

1. **Right-click** on image on techworld-it.com
2. **Save Image As...**
3. Save with descriptive name (e.g., `microsoft-logo.png`)
4. Place in appropriate subfolder
5. Optimize image size (use TinyPNG.com or similar)

## 🎨 Image Optimization

Before uploading images, optimize them:

**Tools:**
- [TinyPNG](https://tinypng.com/) - PNG compression
- [Squoosh](https://squoosh.app/) - Universal image optimizer
- [SVGOMG](https://jakearchibald.github.io/svgomg/) - SVG optimizer

**Guidelines:**
- Keep file sizes under 200KB when possible
- Use WebP format for better compression (with fallbacks)
- Compress images to 85% quality (usually imperceptible difference)
- Resize large images to actual display size

4. **Solutions**: Solutions section/pages

## ⚠️ Important Notes

- **File Naming**: Use lowercase, hyphens (not spaces)
  - ✅ Good: `microsoft-logo.png`, `hero-bg.jpg`
  - ❌ Bad: `Microsoft Logo.PNG`, `Hero Background.jpg`

- **Transparent Backgrounds**: Partner logos should have transparent backgrounds (PNG)

- **Copyright**: Ensure you have rights to use all images

- **Backup**: Keep original high-resolution versions

## 🚀 Quick Start

1. Visit https://www.techworld-it.com
2. Download logo and save as `logo.png`
3. Create favicons (use https://realfavicongenerator.net/)
4. Download partner logos from partners page
5. Save to `images/partners/` folder
6. Download hero/banner images
7. Save to `images/banners/` folder

That's it! Your images are ready to go.
