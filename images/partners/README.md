# Partner Logos

Add partner/customer logos to this folder.

## Required Partner Logos

Download from https://www.techworld-it.com/partners (or similar):

1. **microsoft.png** - Microsoft logo
2. **cisco.png** - Cisco logo
3. **hp.png** - HP logo
4. **dell.png** - Dell logo
5. **vmware.png** - VMware logo
6. **veeam.png** - Veeam logo
7. **ibm.png** - IBM logo
8. **kaspersky.png** - Kaspersky logo
9. **trendmicro.png** - Trend Micro logo

## Logo Requirements

- **Format**: PNG with transparent background
- **Size**: Approximately 400x200px (width x height)
- **Quality**: High resolution, clear, professional
- **Background**: Transparent (no white or colored background)
- **Naming**: Lowercase with hyphens (e.g., `trend-micro.png`)

## Where to Get Logos

1. **Official Brand Pages**: Visit each company's press/media page
2. **Techworld Website**: Download from existing partner section
3. **Logo Databases**: 
   - [Brands of the World](https://www.brandsoftheworld.com/)
   - [Seeklogo](https://seeklogo.com/)

## Image Optimization

After downloading, optimize logos:
- Use [TinyPNG](https://tinypng.com/) to reduce file size
- Ensure transparent background is preserved
- Test on both light and dark backgrounds

## File Naming Convention

```
microsoft.png
cisco.png
hp.png
dell.png
vmware.png
veeam.png
ibm.png
kaspersky.png
trendmicro.png
trend-micro.png (alternative)
```

Use the exact names as shown in the website code for consistency.
